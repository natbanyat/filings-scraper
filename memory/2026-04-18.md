# 2026-04-18

- Ran a targeted source-quality audit after Nat flagged too many non-credible news sources in the pipeline.
- Recent event logs showed repeated low-cred offenders including `fxstreet.com`, `ad-hoc-news.de`, `manilatimes.net`, `bloomingbit.io`, `marketscreener.com`, `insidentity.com`, `bitcoinworld.co.in`, `stocktitan.net`, `news.futunn.com`, and `heygotrade.com`.
- Hardened source filtering in `scripts/config.py` and `scripts/fetch_news.py`: added a conservative `TRUSTED_SOURCES` allowlist, expanded the blocklist for recurring junk domains, switched source matching from loose substring checks to normalized domain-aware matching, and added a source-quality gate so untrusted domains cannot dominate a query when trusted coverage is already available.
- Improved Finnhub source labeling so the pipeline prefers the underlying publisher name over the `finnhub.io` wrapper when Finnhub provides it.
- Added a first-pass official document ingestion layer via `scripts/official_docs_fetcher.py`, which pulls recent SEC filings and same-host IR documents into a normalized schema (`title`, `url`, `source`, `published_at`, `doc_type`, `text_snippet`, `origin`, `form_type`).
- Wrote `research/architecture/official-doc-ingestion.md` to define the next steps toward exchange-specific adapters (HKEX, TDnet/JPX, RNS, SEDAR+) and eventual storage/diffing.
- Fixed Standard Chartered `ir_page` metadata in `scripts/config.py` to `https://www.sc.com/en/investors/financial-results/`, which the new document fetcher can scrape successfully.
