# Skills

These are common workflows Claude Code should support.

Ticker news update

Steps:

1. identify relevant ticker
2. read coverage/tickers/<ticker>/kpi_tree.md
3. map the news event to a KPI node
4. assess impact on thesis
5. write event update into events/ticker_news/YYYY-MM-DD.md
6. if material, append to coverage/tickers/<ticker>/update_log.md

Macro close update

Steps:

1. summarize cross-asset moves
2. identify macro narrative shift
3. identify implications for sectors and covered tickers
4. write update to events/macro/YYYY-MM-DD-close.md

Deep research

Steps:

1. analyze business model
2. identify key KPIs
3. identify consensus view
4. analyze bull/bear debates
5. produce structured research memo
6. save to research/companies or research/subsectors
